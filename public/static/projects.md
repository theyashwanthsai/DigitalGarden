## Evals, Benchmarks and RL Environments

**[evalkit](https://github.com/theyashwanthsai/evalkit)** *(Oct 2026)*: Git-native offline + online evals for agents. Traces, eval results and agent versions live in the repo, no SaaS.

**[jevals](https://github.com/theyashwanthsai/jevals)** *(Sep 2026)*: An LLM/agent eval framework graded by a calibrated decision model. Every result comes with a confidence score, so clear answers can be trusted and only the uncertain ones go to a human or a bigger model.

**[PI-Env Boilerplate](https://github.com/theyashwanthsai/Boiler-Plate-PI-Env)** *(Oct 2025)*: The smallest possible [verifiers](https://github.com/PrimeIntellect-ai/verifiers) v1 RL environment. A template for building new environments.

**[PostTrain-Lab](https://github.com/Turi-Labs/PostTrain-Lab)** *(Oct 2025)*: A modular, educational project exploring LLM post-training, from supervised fine-tuning to reinforcement learning.

**[Poke-Bench](https://github.com/Turi-Labs/Poke-Bench)** *(Feb 2025)*: 1v1 Pokémon Showdown battles between LLMs. Code for our NeurIPS 2025 ER workshop paper.

**[Stochastic-Matmul](https://github.com/Turi-Labs/Stochastic-Matmul)** *(Oct 2025)*: Code for our ICLR 2026 Sci4DL workshop paper on floating-point noise in batch-invariant GPU matrix multiplication.

**[MREB](./mreb)** *(Mar 2025)*: Multimodal Reasoning and Ethics Benchmark, an open-source benchmark for the cross-domain capabilities of AI models. [repo](https://github.com/theyashwanthsai/MREB)

**[awesome-harness](https://github.com/Turi-Labs/awesome-harness)** *(Apr 2026)*: A curated list of resources for building reliable AI agent harnesses.

## AI Agents

**[Devyan](https://github.com/theyashwanthsai/Devyan)** *(Jun 2024)*: A team of agents (Architect, Programmer, Tester, Reviewer) that plans, writes, tests and reviews software from a single prompt. Built before bolt or lovable existed. 290+ stars, and it boosted my career big time!

**[One Person Company](./opb)** *(Feb 2026)*: A 24/7 self-hosted team of AI agents running on a Raspberry Pi, with sessions, learnings and memory. They work as my personal research and content agency. [repo](https://github.com/theyashwanthsai/one-person-company)

**[YAAF2](https://github.com/Turi-Labs/YAAF2)** *(Apr 2026)*: A Python framework for scheduled, memory-aware, tool-using agents. Agents are markdown files, tools are plain functions. Successor to [YAAF](https://github.com/Turi-Labs/YAAF).

**[wiki-builder](https://github.com/Turi-Labs/wiki-builder)** *(Apr 2026)*: Drop in source documents, get a structured, interlinked markdown wiki built by an LLM.

**[Newsletter Agent](https://github.com/Turi-Labs/Newsletter-Editor-Agents)** *(Apr 2025)*: A team of AI agents that runs the official newsletter of [turilabs](https://turilabs.in).

**[AI-Agent-Learn](https://github.com/Turi-Labs/AI-Agent-Learn)** and **[Mastering-Agentic-AI](https://github.com/theyashwanthsai/Mastering-Agentic-AI)** *(Mar 2025)*: Resources, cookbooks and code for building agents with CrewAI, DSPy and MCP.

**[DocGPTBuilder](https://github.com/theyashwanthsai/DocGPTBuilder)** *(Jun 2024)*: A CLI that turns a documentation repo into a single LLM-readable file, for fine-tuning or custom GPTs.

**[Twitter-Agent](https://github.com/theyashwanthsai/Twitter-Agent)** *(Jul 2024)*: A fun little agent with Twitter access.

## Learning ML and Systems From Scratch

**[Learning Intelligence](https://github.com/theyashwanthsai/Learning-Intelligence)** *(Jun 2025)*: Implementing important ML research papers to build research intuition.

**[tinyLLM](https://github.com/theyashwanthsai/tinyLLM)** *(Aug 2024)*: All the code I wrote while reading *Build a Large Language Model from Scratch*. See the [LLM internals series](./llm0).

**[ToyGrad](https://github.com/theyashwanthsai/ToyGrad)** *(Feb 2025)*: Autograd implemented in C.

**[GpuMaxxing](https://github.com/theyashwanthsai/GpuMaxxing)** *(Jan 2026)*: Learning GPU programming to understand how ML models actually run on the hardware. See [GPUmaxxing 1](./GPUmaxxing_1).

**[OS-2](https://github.com/theyashwanthsai/OS-2)** *(Jun 2025)*: A hobby operating system in C, running in 32-bit protected mode. The successor to [OS-1](https://github.com/theyashwanthsai/OS-1), a single-tasking, interrupt-driven x86 kernel in assembly. See the [OS devlogs](./osdevlogs/root).

**[ZenScript](https://github.com/theyashwanthsai/ZenScript)** *(Sep 2023)*: A dynamically typed, interpreted language in Python, to understand interpreters and compilers. Later partly rewritten in Rust as [Rusty-ZenScript](https://github.com/theyashwanthsai/Rusty-ZenScript). Before it came a [Pascal interpreter](https://github.com/theyashwanthsai/Pascal-Interpreter) from scratch.

**[DKVDatastore](https://github.com/theyashwanthsai/DKVDatastore)** *(Jan 2024)*: A minimal distributed key-value database in Go using the Raft consensus algorithm.

**[Opilot.nvim](https://github.com/theyashwanthsai/opilot.nvim)** *(Mar 2024)*: A Copilot clone for neovim using CodeLlama 13B, with a middleware microservice for autocomplete and test generation.

**[TinyReact](https://github.com/theyashwanthsai/TinyReact)** and **[TinyExpress](https://github.com/theyashwanthsai/TinyExpress)** *(Sep 2023)*: Minimal clones of React (JSX, rendering, patching, lifecycle) and Express.js.

**[MDcompiler](https://github.com/theyashwanthsai/MDcompiler)** and **[HTTPserver](https://github.com/theyashwanthsai/HTTPserver)** *(Dec 2023)*: A Markdown-to-HTML compiler in Rust and an HTTP server in Go.

## Tools

**[Roughcut](https://github.com/theyashwanthsai/roughcut)** *(Aug 2026)*: An AI-native, fully local video editor for talking-head videos. Cuts silences, reviews takes, and adds word-synced captions and AI-planned animated inserts. I use it for my Instagram.

**[leetArena](https://github.com/theyashwanthsai/leetArena)** *(Nov 2023)*: Custom rooms to compete with friends on LeetCode questions. Basically multiplayer LeetCode. Plus [leetAPI](https://github.com/theyashwanthsai/leetAPI), a small npm package for LeetCode user data.
